# Запуск проекта

Что делать с проектом, написано в [`README.md`](README.md). Здесь только запуск.

## Что нужно

- Docker с Docker Compose
- 8 ГБ оперативной памяти и около 6 ГБ на диске
- [Ollama](https://ollama.com) версии 0.15.4 или новее, если модель будет работать на вашем компьютере
- `make`. На Windows команды выполняются в WSL

## Модель

Есть два варианта. Выберите один.

**Ollama на вашем компьютере.** Вариант для macOS и Windows: контейнер там не видит видеоускоритель, и модель в нём работает в несколько раз медленнее.

```bash
ollama pull qwen3:4b-instruct-2507-q4_K_M
ollama pull bge-m3
```

В `.env` оставьте адрес `http://host.docker.internal:11434/v1`.

**Ollama в контейнере.** Вариант для Linux.

```bash
make up-llm
make pull-models
```

В `.env` поставьте адрес `http://llm:11434/v1`.

Тег модели пишите полностью. Короткий тег `qwen3:4b` указывает на другую сборку: она рассуждает перед каждым ответом, работает в семь раз медленнее и ломает разбор ответов.

## Первый запуск

```bash
cp .env.example .env
make up
make test
make eval MODE=baseline
```

`make test` сначала покажет 50 упавших контрактных тестов из `tests/contract/` с ошибкой `NotImplementedError`. Это ожидаемо: так выглядит список работ. Тесты платформы из `tests/infra/` и `erp/tests/` при этом проходят.

`make eval MODE=baseline` прогоняет открытые вопросы через готовый плоский RAG и пишет отчёт в `artifacts/eval_baseline.json`. Первый запуск занимает несколько минут, повторный берёт ответы модели из кеша `artifacts/llm_cache/`.

## Команды

| Команда | Что делает |
| --- | --- |
| `make up` | собирает и запускает сервисы `app` и `erp` |
| `make index` | строит граф, сообщества и сводки вашими функциями |
| `make ask MODE=local Q="..."` | задаёт один вопрос в режиме `baseline`, `local`, `global` или `agent` |
| `make eval MODE=local` | прогоняет открытые вопросы в одном режиме |
| `make eval-all` | прогоняет открытые вопросы в четырёх режимах |
| `make eval-extraction` | измеряет качество извлечения на эталоне |
| `make test` | запускает тесты |
| `make lint` | запускает линтер |
| `make down` | останавливает сервисы |

## Работа без Docker

Если установлен [uv](https://docs.astral.sh/uv/), те же команды работают без контейнеров:

```bash
uv sync
uv run uvicorn erp.app:app --port 8100 &
make test RUN="uv run"
make eval MODE=baseline RUN="uv run"
```

В этом случае в `.env` укажите `LLM_BASE_URL=http://localhost:11434/v1`.

## Если что-то не работает

- **«сервис модели недоступен»** – Ollama не запущена или в `.env` неверный адрес. Проверка: `curl http://localhost:11434/api/version`.
- **Модель отвечает очень медленно** – проверьте тег модели и то, что другие тяжёлые программы закрыты. На 8 ГБ памяти модель и Docker занимают её почти целиком.
- **Числа в отчёте не меняются после правки кода** – ответы берутся из кеша только при том же запросе. Если вы изменили запрос к модели, кеш не мешает. Чтобы начать с чистого листа, удалите `artifacts/llm_cache/`.
